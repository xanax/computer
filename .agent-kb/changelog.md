# Changelog

Newest first. One line per task. Current truth is in `areas/`, not here.

2026-10-03 — chat-index-summary — `/index` is now a search-icon button beside the `+` in the composer, not just a slash command: same classes as the `+` (so mono renders it solid ink, no grey), gated on `hasChatContent` and disabled while streaming. Server had already restarted past the route, so it is live; a real browser click returned 200 and rewrote the summary. Superseded: Phase 2 needed a restart.
2026-10-03 — chat-index-summary — Phase 2: `POST /api/chats/{id}/index` + `/index` composer command refresh one chat's index for free (no model), sharing `cptr/utils/chat_index.py` with the backfill so the two cannot drift; verified 9/9 in-process against a DB snapshot, entry byte-identical to the builder. Corrected a wrong KB claim: `update_summary`'s `updated_at=0` default *zeroes* the timestamp rather than leaving it.
2026-10-03 — chat-index-summary — `chats.summary` was ranked above message content by `search_by_text` and returned by four surfaces, yet empty for all 378 chats. Backfilled from data already on disk with no LLM calls — 120 from an existing compaction checkpoint (plus the paths touched after it, which the checkpoint cannot describe), 258 composed from the opening question, `function_call.arguments` file paths and tool counts. 378/378, re-runnable, `updated_at` untouched. Deliberately no English labels or dates in the composed form: `summary` is substring-matched into the ranker, so they would flood every search.
2026-10-03 — workspace-pane-identity — Switching workspace and clicking the pinned **chat** tab showed — and then wrote — the *other* workspace's conversation: the launcher id `chat` exists in every workspace and Svelte reuses a keyed block whose key matches, so the incoming pane inherited the outgoing `ChatPanel`. Panes are now keyed by workspace path + tab id; verified with the cdp harness on a live pair of workspaces and against the DB rows (B-020).
2026-10-02 — mono-codemirror-rendering — Mono editor read as ink-on-ink: the cursor line's text was never flipped and a selection's slab is painted behind the glyphs. Cursor line, selection (shared `editor-mono.ts` mark, both CM mounts) and the carets now invert, verified 0/255 in `bw` and `bw-dark` (B-018).
2026-10-03 — workspace-state-ownership — The workspace prompt "saved" and then reverted: the layout autosave echoes the whole object it read (prompt included) and `put_workspace` only guarded keys the body *omitted*. `prompt`/`services`/`toolServers` are now server-owned on the layout PUT and the store drops `prompt`/`services` at load; repro/verify over HTTP on an isolated instance (B-019).
2026-10-02 — frontend-reactivity — Dashboard clicks died: a no-op store notify rebuilt the board between pointerdown and pointerup; guarded both (B-017).
